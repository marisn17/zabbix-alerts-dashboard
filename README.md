# 📊 Zabbix Alerts & Triggers Dashboard

Projeto de **coleta, tratamento e análise de alertas**, utilizando dados extraídos via **API do Zabbix**, com geração de relatórios em **CSV/Excel** e visualização em **Power BI**.

Este projeto foi desenvolvido para fins de **estudo e portfólio**, sem uso de dados reais de empresas.

---

## 🧠 Visão Geral

A solução é composta por três etapas principais:

1. Extração de dados via API do Zabbix  
2. Processamento e normalização com Python (Pandas)  
3. Visualização dos dados em Power BI  

---

## 📈 Principais Análises

- Quantidade de alertas por Host  
- Triggers com maior volume de alertas  
- Distribuição de severidades  
- Análise temporal de alertas  

---

## 🛠️ Tecnologias Utilizadas

- Python  
- Pandas  
- Zabbix API (JSON-RPC)  
- Power BI  
- Excel / CSV  

---

## 🔒 Privacidade

Todos os dados apresentados são **fictícios ou anonimizados**, sem qualquer referência a ambientes reais.
